পুরনো পাতার progress Export

এই ফাইলটা G:\IELTS-এ রেখে, যে browser-এ পুরনো পাতাগুলো খুলতেন, সেই browser-এ খুলুন। তারপর নিচের বোতাম চাপুন। নামা .json ফাইলটা নতুন সাইটের Progress → Import-এ দিন।

    Chrome আর Edge-এ কম্পিউটারের সব HTML ফাইল একই storage ব্যবহার করে, তাই এক জায়গা থেকেই সব পাওয়া যায়। Firefox প্রতিটা ফোল্ডারের storage আলাদা রাখে; সেখানে এই ফাইল পুরনো পাতার একই ফোল্ডারে রেখে খুলতে হবে।
